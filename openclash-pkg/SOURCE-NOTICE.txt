The official binary is not modified or stripped. Its original GPL license and
this notice are installed with the core. The corresponding fixed source archive,
including upstream build scripts, is distributed beside the APKs in sources/.
The exact upstream download, compressed SHA256 and decompressed SHA256 are in
inputs.json and packaging-manifest.json. External Go dependencies are identified
by the upstream go.mod/go.sum and upstream build scripts. No claim is made that
this package rebuilds the upstream release binary reproducibly.

Core is installed as /etc/openclash/core/clash_meta, with no independent service.
OpenClash ships its upstream enable=0 default. Upstream UCI defaults still
register a firewall include and adjust LuCI/uhttpd upload and timeout settings;
disabled proxy state does not mean installation has no configuration effects.

F50 currently lacks UDP_DIAG/RAW_DIAG. Upstream Linux process lookup uses TCP or
UDP INET_DIAG only; missing UDP_DIAG affects UDP process/UID rules, not core
startup or ordinary proxy/TUN forwarding. This limitation is not hidden by a
fabricated dependency provider or a core modification.

APK signatures are generated by this packaging run. The fresh private key exists
only in /dev/shm and is not exported. Ship the generated public key with the APKs;
this is not an OpenWrt or upstream release-author signature.
